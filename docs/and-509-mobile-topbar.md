# AND-509：紧凑控制台顶栏与筛选

采用已选定的 v3 两行布局：导航与项目操作一行，会话及 Agent 筛选一行。布局断点为 1023px，与既有紧凑外壳一致；不改变桌面搜索、侧栏导航及类型筛选。

## 共用实现与覆盖入口

| 对象 | 变化 | 保留的边界 |
|---|---|---|
| App 控制台顶栏 | 搜索进入更多首项；复用顶栏展开搜索 | 返回、项目、待集成、更多常驻；不增加集成权限 |
| AgentConsoleSearch | 搜索关闭回到更多触发器；快捷键复用同一打开流程 | 搜索值继续由页面持有，关闭不清除；父草稿层不被搜索往返关闭 |
| ProductSwitcher | 仅名称省略；紧凑收起值隐藏零未读，大于99展示99+ | 图标、箭头和非零提示保持；可访问名称及展开菜单读取完整数量 |
| AgentSessionConsole | 状态与类型进入一个会话筛选弹层 | 复用公共 Modal、Select、计数及原处理器；两项独立组合，立即生效；Agent 保留独立入口 |

顶栏动作菜单的紧凑点击高度统一至少44px。复用主题、字号、边框、圆角和浮层生命周期，无新增样式豁免、接口或业务写入。普通、条目、集成、收藏及归档会话继续使用原分类与过滤规则。跨项目提醒、错误和批量操作是按状态出现的内容，不伪装成第三条常驻导航。

## 验证记录

- 新增实际页面审计：320、360、520、521、1023、1024px，明暗主题；紧凑端三档字号检查控件位置、图标和箭头、页面溢出及两行高度。
- 120个未读会话验证99+视觉提示、完整可访问数量及展开数量；大字号验证徽章与图标、箭头互不重叠。
- 搜索菜单第一项、44px触控、关闭恢复焦点、保留搜索、键盘快捷键及浏览器返回；新建草稿层中的搜索往返不清空草稿或关闭父层。
- 状态、类型、Agent独立组合与原计数；嵌套Select的Escape只关闭顶层，关闭筛选弹层回到触发器。
- 原搜索、用途分类、项目导航、选择器、Web工具栏及新建会话测试按新紧凑入口调整。相关65项浏览器审计通过；最后的触控与快捷键补充后，17项受影响场景再次通过。
- 最终 `npm run check` 通过，覆盖lint、身份/迁移/样式检查、单测、类型、构建和性能门禁；公共浮层契约检查及 `git diff --check` 通过。样式基线未扩大。
