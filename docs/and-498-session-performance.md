## 变化与边界

| 对象 | 变化 | 保留的边界 |
|---|---|---|
| 会话定位 | 按目标身份定向读取成员，复用批量摘要 | 账号与全组产品授权、节点歧义、项目/受管隔离 |
| 已存聊天 | SQL 选择有界键后按字节预算逐条读取正文 | 来源优先、去重、顺序、旧游标及完整原文 |
| 当前请求与方案 | 当前表单与审批依据独立读取 | 历史只读，不复活旧请求或过期方案 |
| 列表 | 批量审批/原生状态；按时间桶累计轮次 | 全量列表、完整计数、严格早于、状态及多条目最大轮次 |
| 外部进展与附件 | 进展独立分页，保留附件元数据 | 不伪装为聊天；默认完整详情及 MCP 完整读取兼容 |

共用组件：`useAgentHistory`、`withCurrentRequests`、`AgentSessionQuestions` / `PermissionQuestion`、`AgentProgressReports`。覆盖 `AgentSessionConsole` 与条目内 `AgentSessionPanel`；复核原 `AgentPlanRecords` 和方案批准入口。没有新增样式或样式豁免。

新增迁移 `202611100633` 仅加查找/分页索引，不删除或改写源历史。大成员组使用数据库窗口去重，502 个同源历史交接记录仍可正常翻完；小组继续使用索引定位。
