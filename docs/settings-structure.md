# 设置结构 V2

个人、产品、全站配置分开标注作用范围。沿用现有设计令牌、权限判断和领域接口。

| 分组 | 主入口 | 内部层级 |
| --- | --- | --- |
| 个人设置 | 资料与安全 | 昵称、邮箱、密码 |
| 个人设置 | 显示 | 主题、语言、字号 |
| 个人设置 | Agent 配置 | 连接与授权；执行设备 → 设备详情；派单默认值 |
| 产品设置 | 产品配置 | 产品卡片列表（搜索、正常/已归档筛选）→ 产品概览 → 基本资料、模块、管理员、发布配置、SDK 接入 |
| 管理设置 | 账号与权限 | 搜索或按产品筛选账号 → 账号详情及各产品权限 |
| 管理设置 | 产品管理员 | 各产品及已配置管理员 → 指定产品的管理员设置 |
| 管理设置 | 模型 | MissionGo 自身 AI 功能使用的模型服务配置 |

## 配置归属

派单默认值属于账号，包含默认设备、Agent、权限模式、模型、推理强度。整个账号共用一套，查看设备或切换产品不会创建另一套默认值。

个人访问令牌和客户端授权属于账号，按账号当前产品权限生效。SDK 令牌属于指定产品，可以进一步绑定模块；不同产品使用各自的令牌，一个产品允许多枚。两类令牌保留各自的服务端能力和撤销逻辑。

模型入口承接已有的全站模型服务配置。派单模型由设备上 Agent 的实际能力提供，与全站模型配置分别管理。

## 权限与导航

管理员在账号与权限中编辑账号和产品授权。产品创建者从相同主入口先选择自己创建的产品，再进入其授权界面，继续使用已有的产品范围接口，不获得全站账号列表、账号创建、停用或删除能力。

产品概览的权限快捷入口跳到账号与权限。管理员进入按该产品筛选的账号列表；产品创建者进入自己产品的授权界面。产品配置不再维护独立的权限编辑页。

产品选择和新建操作位于产品配置内部。列表不自动跳入当前产品；详情保留快捷切换和返回列表入口。设置列表单独读取已归档产品，工作区切换器仍只显示正常产品；归档后可从“已归档产品”进入基本资料恢复。没有产品时提供创建第一个产品的入口，创建成功后进入其概览。

桌面保留主导航，内容区逐层进入；手机从设置目录进入模块和详情。详情支持独立 URL、刷新、上级导航和浏览器返回，离开有修改的页面继续使用未保存保护。旧的 AI 连接、设备、派单、产品权限和全站 AI 服务链接仍可打开对应配置。

每一屏只有一个返回控件：顶部返回箭头指向上一级，一次只退一级（详情 → 所属模块 → 设置目录 → 工作区），其可读名称就是上一级名称。页面内不再叠加「设置目录」条和面包屑返回，系统返回手势与它走同一层历史，避免两个返回箭头并存或一次退两层（AND-316）。

## 批次总览

统计中的固定批次先展示列表，提供名称搜索、条目数和当前交付率，选择后进入详细进度。详情使用 `statsBatch` 参数支持刷新及从条目返回；返回批次列表清除此参数。批次仍仅自己可见，进度不随报表筛选改变；部分条目不可访问时不计算交付率。列表接口一次读取可见成员的当前状态，不加载每个批次的完整历史。
