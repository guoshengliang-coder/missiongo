# AND-512 账号级常用指令

## 行为与组件

常用指令是账号私有的文字片段，不是系统规则、权限批准或自动任务。选择仅插入草稿，由用户主动发送。内容必填（最多 3000 字），短名称可选（最多 20 字），最多 200 条；同名允许。收藏只影响选择列表分组，不增加聊天输入框常驻栏。

共用 `CommonCommandProvider`、`CommonCommandMenu`、`CommandEditor`、`CommonCommandSettings`、`CommandMessageMenu` 和 `useCommandTarget`；复用 `Modal` 头部操作、`OverlayMenu`、原设置路由、主题令牌及发送锁。覆盖控制台既有会话、新会话和条目内会话面板。

- 输入加号保留原上传能力，新增常用指令。旧节点禁用上传时仍可选择文字指令。
- 选择弹层搜索、收藏优先、整行插入；管理和新增位于右上方，无列表底部提交。
- 设置个人分类新增常用指令管理，无搜索；支持收藏、排序、编辑和删除。会话入口返回原选择弹层、搜索、位置和草稿；设置目录入口按原层级返回。
- 用户侧文字消息提供竖向三点，触屏常驻、桌面悬停或键盘焦点可达；长按只是辅助，不阻止系统文字选择。菜单复制或预填新建指令，保存返回会话。没有逐条消息下的常驻保存提示。
- 短名称不随指令发送。附件文件、原生附件提示不存为指令。只使用现有可见消息，不增加会话读取权限，不根据 user role 断言当前账号是原作者。

## 存储、并发与失败

HTTP `GET /api/v1/common-commands` 读取，`POST /api/v1/common-commands` 仅接受 create/edit/delete/favorite/move 五种领域动作。服务端从认证上下文确定 owner，客户端不能指定另一个账号。表 `account_common_commands` 独立于会话收藏与账号权限；迁移编号为 UTC 时间戳。

写操作使用集合 revision，编辑/删除绑定打开表单时的版本。请求标识和内容摘要按账号持久化，同一次失败重试不重复创建，变更请求复用旧标识会拒绝。冲突保留草稿并刷新数据，编辑表单显示另一设备最新正文供核对；用户主动再次保存才使用新版本，不自动覆盖。变更通过已有账号范围 config 事件失效查询，不增加轮询、不把正文广播给其他账号。换账号清除临时指令状态。

输入按光标位置插入，保留选区文字；发送长度超限时拒绝插入，不截断。插入后继续编辑会隐藏旧撤销，以免清掉新输入。现有发送去重、未知送达、附件和权限问答处理保持。
