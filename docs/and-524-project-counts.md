# AND-524 项目下拉计数

控制台项目下拉选项将单一未读数字改为两个带标签的会话计数：“待处理 N”“未读 N”。零值弱化但保留文字，非零使用既有警告及未读语义色。数量分别说明，不合并相加。

## 范围与复用

- 共用 `ProductSwitcher`、`ProductBadge`、`Select.fitContent`、i18n 和主题令牌。新增样式仅作用于项目选项内的计数，未增加样式豁免。
- 覆盖桌面控制台及紧凑控制台的同一项目切换入口；菜单可按内容适配，在视口限制内换行，长项目名及精确计数保持可读。
- 仅展开时展示两项计数。收起值及其紧凑零值隐藏、99+ 和无障碍精确数量不变。非控制台项目切换不展示会话计数。
- 列表上方黄色提示、左侧导航、选择项目及关闭浮层行为不变。不新增接口请求或改变缓存、刷新、后端、权限及状态判定。

## 统计边界

`agentAttentionCounts` 使用与现有控制台相同的项目归属、归档排除及 `needsAttention` 判定，以会话 ID 和项目去重。数据来自 App 的同一 `allAgentSessions` 快照；未加载时不伪造零值。

未读继续由 `agentUnreadCounts` 计算，排除归档和 `active` 会话。异常未读按现有规则保留。待处理与未读可能重叠，各自独立计数。

跨项目会话可在多个项目各计一次。黄色提示 `agentOtherProjectCounts` 对其他会话计数，并排除任何关联当前项目的会话，因此不是其他项目数字之和。左侧数量还受 Agent、关联类型及搜索影响。只有无跨项目会话、无额外筛选、相同快照时才检查数字直接对应；其余按既有范围核对。

## 验证

- 统计单测覆盖重复会话、重复项目关联、跨项目、归档、运行中未读和空数据；保留原未读及其他项目统计回归。
- `and-524-project-counts.audit.spec.ts` 覆盖展开标签、零值、共享会话边界、搜索、收起值、非控制台入口、加载及事件刷新；布局覆盖 320/375/520/521/768/1023/1024/1440px、明暗主题和三档字号，检查长名称、120 精确计数、返回与焦点。
- 复查既有 `agent-console-product-switch.audit.spec.ts`、`and-509-mobile-topbar.audit.spec.ts`，保证项目切换和紧凑顶栏契约。
