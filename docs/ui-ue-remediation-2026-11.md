2. 静态检查使用有边界的源码模式匹配，不能识别所有动态写法；新增界面仍需按问题族补回归。Linux 视觉基线由 CI 比较，本机 Chromium 实测和截图不能替代它。
3. 当前没有连接 Android 测试设备，未验证 Android 真机/系统返回手势、Safari 和 macOS 原生页面。本次原生改动仅在 Android SDK；不以 Web 通过宣称所有宿主通过。
4. Web 发布不会自动升级集成了旧 SDK 的宿主。发布时需分别更新 Web 与 SDK/Android 产物，核对实际版本；Android 发布声明可关联真实工作条目，无条目时使用说明文字并关联 PR，不虚构编号。macOS 发布声明暂保留编号要求，以兼容已安装客户端。
5. 原始审计截图保留在 `review-evidence/ui-ue-2026-10/`；它们用于说明修复前的问题，不作为修复后的证据。[整改后截图](review-evidence/ui-ue-2026-11/README.md)独立保存，已检查手机/桌面明暗布局及 320px 大字号控件可见性。

## 发布前补查：菜单转编辑与窗口缩窄

主线 `65d01eb` 的窄屏工具栏菜单转编辑后，关闭弹窗会退回整个工作区，未回到可见的更多按钮。共享 `OverlayMenu` 现在在菜单动作关闭时先恢复触发器，再由新弹窗在子表单自动聚焦之前记录返回位置。共享 `useModalSurface` 验证恢复是否成功，跳过隐藏、不可交互或已移除的目标；窗口缩窄导致原按钮隐藏时，优先回到当前详情等可见内容区。`overlay-contract.audit.spec.ts` 覆盖 320px 大字号菜单转编辑的 Back/Esc/取消、桌面直接编辑，以及编辑中缩窄窗口后的焦点恢复。
