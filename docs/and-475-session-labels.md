# AND-475 会话类型标签与命名

## 行为与范围

列表默认不展示派单类标签，详情标题保留“派单会话”；集成、非派单两类在列表和详情继续显示。筛选统一使用“派单会话／非派单会话／集成会话”，辅助名称为“会话类型筛选”，英文名称同步更新。

用户在审阅时明确选择保留详情标签，本轮按获批 v3 实施。仅调整展示，不改已有会话标题、持久化类别、关联条目、领取权限、执行状态或筛选计数口径。

## 共用组件与覆盖入口

| 对象 | 变化 | 边界 |
|---|---|---|
| `SessionCategoryBadge` | 列表入口传入 `list`，仅 linked 返回空 | 详情默认保留三类标签；集成判定仍优先 |
| `agentSessionCategory` | 沿用已有分类判定 | 项目会话领取条目后仍归派单；旧响应沿用关联回退 |
| i18n 与 `Select` | 统一中英文名称、筛选辅助名称 | 保留筛选键、草稿、已选值和计数行为 |
| 主题样式 | 沿用现有颜色、字号与布局 | 无新增 CSS、组件皮肤或样式豁免 |
