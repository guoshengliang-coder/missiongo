## 行为变化

- `get_item_context.releaseObservationDiagnostics` 按交付 ID 返回只读诊断；只使用已登记 completion 的精确产品、仓库和 production 快照，不猜关联。
- 缺集成依据、无仓库身份、未找到快照、无效快照、读取失败、历史依据和可读取快照分别表达。较新空快照不会与旧产物拼接；同仓库多交付共享去重的观察，正式覆盖仍逐交付核实。
- 最多返回最近 20 份相关交付诊断，明确 `total`、`limit`、`truncated`；原始正式交付与时间线接口不变。已有历史说明可保留为 historical，但不附当前仓库快照。
- `unverified` 和 notice 明确观察仅为定位线索。读取不访问 proof URL，不检查 Git 祖先关系，不写正式回执、状态或时间线。
- 产品直接读取权限之外的单条协作访问省略观察字段；不泄露产品级发布快照、本机路径、节点身份或凭据。旧客户端缺字段不等于未上传。
- Skill 源码升级到 5.69.0，区分集成、本地打包、正式分发和证据交接四个事实；已授权发布的收尾分别核对部署、逐条交接及通知结果。失败和缺口具体记录，不能停在“部署成功”或凭据上传处；未知结果与幂等重试保持原边界。
