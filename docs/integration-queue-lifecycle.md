# 待集成清单：历史轮次、无需发布交接与待核对

## 范围与诊断

本轮为项目会话开发，复用用户已批准的迭代范围，不领取或修改任何工作条目。

- AND-501、AND-435 的旧轮次交付已有发布回执，但当前轮次读取会漏掉旧完成事件，使旧清单记录显示为待发布。
- AND-450 的早期无需发布交接缺少 developmentEventId；旧判断忽略了同轮次、同完成依据的正式交接事件。
- 清单原先将异常与正常待发布合并，角标因此包含不能直接执行的记录。

## 最终行为

| 对象 | 变化 | 边界 |
|---|---|---|
| 历史轮次 | 旧交付进入只读历史，保留原发布回执与后续返工说明 | 不将旧回执套给当前轮次 |
| 无需发布 | 精确识别正式交接，显示“无需发布／已交接” | 人工移动状态不能代替交接证据 |
| 待核对 | 单列异常、显示原因及原详情入口，禁止选择执行 | 不补造证据或自动恢复授权 |
| 计数 | 主角标只计待合并与待发布；全部列表包含待核对 | 历史不计待办 |
| 存量缓存 | 时间戳迁移标记显示投影待重建 | 不改写交付原文、条目事件、状态或验收 |

历史读取仅用于清单展示；默认领域读取仍限制在当前轮次。无 ID 的早期回执必须同时满足：同处理轮次、同完成依据、最近的前置开发事件，且必须是正式的无需发布交接。AND-450 实际早期回执还缺少完成引用；这种情况只接受同轮次唯一开发事件、显式无需发布范围、相同内容版本、直接衔接的修订号及 Agent 正式交接事件，任一条件缺失均不推断完成。不同轮次不能匹配。分组里仍存在当前轮次未完成内容时保留待核对，不能因其中某个旧轮次而隐藏整组。

## 共用组件与入口

复用 PendingMergeButton、QueueFacts、MergeDialog、QueueHistory、Modal、既有详情层与 i18n；不增加 CSS 或样式豁免。覆盖项目控制台入口、清单阶段筛选/全选/执行选择、详情返回与交付历史。Web 展示亦用于 Android 内嵌页面；原生包不在本次改动范围。

另一次 CI 在合并提交引导的 44px 检查读到 43.999969px，为模态位置引起的几何浮点误差。测试现在同时断言计算样式 min-height 至少 44px、实际几何高度按千分之一 CSS px 计至少 44px；不改样式或尺寸契约。控制台/条目面板、320px/1440px、明暗主题、三档字号的 8 项场景通过。

## 历史轮次的证据边界补强

历史分类必须能在原始非导入时间线中找到对应轮次锚点。缺少轮次、null 或不存在的锚点均进入待核对，不能静默归档；不提供可执行的交接记录。新增显示投影重算迁移，仅更新展示，不改业务事件和状态。三种反例验证留在待核对、拒绝执行且条目阶段保持；原有已发布后返工、无需发布兼容、部分发布及账号隔离回归继续保留。此补修仍属于原批准的缺证据分类范围。

## 标准发布性能门禁补修

标准门禁两次在批次历史读取 CPU 预算上阻断（归一化约 0.835 / 0.847 ms，预算 0.8 ms）；临时副本均由门禁清理。补修只读取仍为 pending 且对输入敏感的活动边界，已正式发布、无需发布及其他历史状态不再查询无关聊天活动；保留实时失效判断、账号与产品过滤、完整返回字段和每次独立对象，不引入跨请求缓存。

相同合成数据形状（20 批次、200 份交付），七组 CPU 样本中位数由 0.66409 ms 降至 0.46107 ms，约下降 31%。此结果仅用于比较实现，不代替标准生产性能门禁。新增回归覆盖混合已发布/待发布、输入引起 pending 失效、全部发布后无活动查询，以及调用者修改结果不能污染后续读取；专项 101 项通过。性能预算、发布门禁和生产数据访问范围保持不变。

后续标准门禁仍在同一 CPU 目标上测得 0.833 ms（预算 0.8 ms），其余目标通过，临时副本清理成功，未执行生产部署。进一步使用合成数据分项测量定位到会话阶段逐行转换开销：改为 SQLite 聚合阶段映射，并复用八种固定投影读取 SQL 的预编译语句；每次仍查询当前数据库并重新解析结果，不缓存业务行、账号参数或返回对象。活动查询仍按当前待发布范围实时执行。会话阶段保留产品、账号、指定会话过滤和实时过期判断。

新增回归覆盖到期边界、未来与无期限阶段、特殊字符会话 ID、空结果、跨账号与产品隔离，以及预编译读取后写入立即可见。原冷/热读测试区分首次编译与语句复用，仍校验全部读结果与完整重算一致，热读准备次数稳定、冷/热上限均不增加。102 项交付专项通过。同一合成形状的 CPU 中位数进一步从 0.46107 ms 降至 0.36903 ms；生产门禁仍需在合并主线 CI 完成后重新验证，不能以合成结果宣称标准检查通过。
