## 第二轮：运行、恢复与来源隔离

- 修复私有日志读取上限从主线 512 MiB 回退为 16 MiB 的移植遗漏。已有快照协议允许约 30 MiB 内容，原限制会造成成功保存后无法读取或继续更新；恢复主线限额，增加大于 16 MiB 快照的读回及更新回归。
- 外部桥接新增只读轻量控制检查，不进入命令队列、不写日志、不读取完整正文；旧宿主仅在明确不支持时退回只读观察。OpenCode 控制同样使用控制视图。真实宿主回归确认两秒历史读取期间外部输入已经送达，且不重复投递。
- 原生权限等待时，Web 普通文字仍不能变成工具批准，但明确停止当前回合不再被权限卡阻止。
- 控制快照不覆盖外部正文证据缓存；宿主轻量快照缺正文时，产物按精确原生引用、Agent 和来源消息使用已有镜像证据，避免预览短暂失效。没有扩大任意文件读取范围。

## 第三轮：更新状态、包来源与交付门禁

- 更新检查在任何异步读取或更换更新源之前取得状态锁；检查中和安装中不能重叠检查。下载完成事件必须匹配当前目标版本，旧版本完成不能让新版本进入可安装状态。

- 清单版本必须与不可变安装包文件名中的版本一致。
- Windows 产物影响范围补齐共享 Web 源码及锁文件，与已声明的构建来源范围一致，避免草稿、品牌、依赖等改动漏记 Windows 产物。
