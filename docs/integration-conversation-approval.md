# 集成会话审批与核验

当前会话展示待决版本的完整人类摘要。当前账号在原会话阅读唯一有效卡片后，独立发送“同意／批准”或“不同意／拒绝”可记录决定。疑问、条件、引用、附件、多个待决请求、过期阅读及权限变化均不能自动判定。按钮与会话使用同一领域记录，重试不重复批准。

## 授权与执行边界

决定不证明外部操作结束，不执行 Git、发布或验收。执行恢复时另行检查未结束发布、修复预留和未完成命令；执行者继续核实真实 Git、安装和运行事实。原会话仍在回复不阻止保存决定。节点离线保留决定，继续入口复用同一会话与请求键。

原生恢复仅读取原账号、原派单、原节点和原会话的可信完整历史。必须有精确最终审阅文本、独立用户决定、来源标识及原始时间依据；缺失或冲突保留具体缺口。工具不能接收 Agent 自述的 approved。项目无条目方案使用原项目派单及固定文档；不创建或领取条目。外部注册的无条目会话暂不支持此固定文档绑定。

## 只读公开核验

统一入口新增 verify，接受完整原部署回执、最新完整候选分页及适用的冻结范围。实际部署 head、全部产物快照必须与原回执相同，核验前后都检查；变化时重新对账。该动作只读取生产与公开下载，写入新的本地核验回执，不重新构建、部署、切换或覆盖旧失败证据。仍执行原覆盖、来源及摘要门禁。

下载采用流式摘要、最大字节数、总时限及无数据时限；持续有数据的大包不受旧固定短时限影响，停滞和超限仍失败。失败不等同于未部署，公开核验也不能证明用户设备已安装。

## CI 与进度

main 仅在可追溯的完整主线 UI 证据（视觉及全部八个审计分片）存在时，按累计差异复用基线；未知路径、共用影响、缺证及定时检查回退完整验证。required checks 和断言不放宽。新生成进度突出阶段变化、失败和需要人决定的范围，不修改已有原生消息。

## 验证与交付

领域测试覆盖权限、精确范围、来源完整性、事务回滚、幂等及执行保护；浏览器覆盖窄屏和桌面明暗模式、卡片审批与草稿保留，并复查既有交付入口。下载和只读核验使用受控流及快照漂移用例。仓库完整检查与真实节点、生产发布、全机工具安装是独立证据，后者需要对应授权与实际执行。
