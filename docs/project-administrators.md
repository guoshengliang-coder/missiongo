# 项目管理员与 Builder 分配

系统管理员在「设置 → 管理设置 → 项目管理员」选择项目，授予或取消账号的项目管理员角色。一个项目支持多名管理员，一个账号也可以管理多个项目；只有系统管理员可以更改这些授权。

项目管理员可以查看被授权项目，在「产品配置 → Builder 分配」配置来源模块的默认 Builder，并在该项目任意条目的详情中分配、转交 Builder。模块默认值用于新条目，不批量更改已有条目。Builder 候选仍必须是未停用、具有该项目 AI 操作权限的账号。

项目管理员角色独立于全局管理员/普通账号身份和产品的查看、操作、AI 权限。授予此角色不会自动授予条目编辑、执行安排、AI 操作、系统账号管理或其他项目的权限；原有 Builder、产品创建者和系统管理员的交付管理权限保持原规则。项目管理员若同时符合原有规则，仍可按原权限安排执行。

角色授权保存于独立关系表，普通产品权限的修改不会覆盖它。取消角色立即收回角色赋予的查看及 Builder 管理权限，保留账号原有产品权限。停用账号时授权不生效，删除账号或产品时清除对应关系。角色配置采用比较当前授权列表后保存的方式，避免并发配置互相覆盖。
