# AND-512 三轮独立审计与补修

审计对象是账号常用指令完整实现及横向消息菜单调整。三轮由三个独立只读审查上下文完成，主会话核对、补修并执行验证；未扩展为推荐回复、自动回复、合并或发布。

基线为已核实的远端主线 `6e1ffb7b`，审计前本地实现为 `d27a82b6`。用户授权最多三轮，实际执行三轮。

## 第一轮

- 新会话重复渲染插入撤销提示：删除重复位置，浏览器断言只出现一个撤销按钮。
- 编辑器首次读取失败没有原位重试：增加加载状态及重试，保留用户输入；无集合快照时禁用保存。
- 主会话补查：撤销绑定原目标会话；账号切换后旧写响应不得写回缓存或修改新表单；保存响应保留较新集合版本。
- 扩充新会话实际点选测试后，动态发现父会话浮层使 `afterOverlaysClose` 永不触发选择器；改为公共 `afterTopOverlayCloses`，只等待当前层退出，保留父层。覆盖选择、设置往返及草稿不丢失。

## 第二轮

- 迟到 GET 同样会覆盖较新缓存：读取和写入共用版本比较；用真实 TanStack QueryClient 验证挂起旧读取、完成新写入、释放旧读取后缓存不倒退，浏览器另测迟到 POST 与账号配置事件交错。
- 删除冲突反复提交旧版本：保留原版本保护，冲突后禁用原确认，明确要求关闭后重新选择核对；不自动提升版本删除其他设备修改的内容。浏览器覆盖冲突、取消、核对新内容并重开删除。
- 权限答复复制／保存与可见文本不一致：两个入口均向菜单提供正文同源的 `permissionReplyText`；插入及撤销也按可见输入内容处理，再沿用原有精确 wire 转换，不增加权限或自动发送。浏览器验证可见授权答复与预填一致。
- 对按 DOM 索引恢复展开状态的风险进行补强：改为从原目标 textarea 向上展开祖先，不依赖记录排序。该风险最初由代码审查提出，未把它冒充已在生产复现。

## 第三轮

- 独立 DOM 命中检查确认，移动端 44px 点击区域覆盖正文首行顶部：点击区向上移动，SVG 反向补偿，保持原视觉位置、右侧留白、16px 图标和44px触控尺寸；浏览器增加正文字符顶部命中检查。
- 撤销补上账号代次约束：相同目标 ID 和相同输入也不能恢复上一个账号的撤销草稿；清理动作同步更新代次，迟到请求不结算新账号操作。此边界基于代码审查，未完成真实多账号跨设备切换验收。

## 验证边界

本轮验证使用隔离测试数据库和浏览器，不执行真实消息发送、生产修改或发布。已有服务器存储测试、版本冲突与请求幂等测试继续保留。

真实 iOS/Android WebView 长按与系统选区、生产环境跨设备同步及真实账号切换仍需在目标环境验收。模拟触控、DOM 命中与代码审查不替代真机验收。检查的实际最终结果在本文件后续记录及条目交付评论中列明。

## 最终结果

- 第三轮内的补修只读复核通过，没有发现补修引入的明显回归；未增加第四轮。
- 完整 `npm run check` 通过，包括 257 项脚本测试、真实发布入口演练、各模块测试、类型、构建、契约、样式及阻断式性能检查；既有 2 项 skip 保留。
- 最终浏览器回归 15 项通过，覆盖新会话 375/768/1440、主会话 390/1440、管理页 320/1440 明暗主题与三档字号，以及读写交错、失败重试、删除冲突、可见授权正文、跨会话撤销、触控字符命中、执行记录插入后的原面板恢复。
- 真实 TanStack QueryClient 的迟到读取回归通过。最终 UI、类型、lint、样式与差异检查通过。
- 审计过程中新增场景曾复现新会话入口等待父浮层关闭的问题；失败测试在修复后通过，没有通过放宽超时或删除断言来绕过。
- 本轮仅本地补修与提交，未推送、建 PR、登记待集成、合并或发布；条目状态不变。
