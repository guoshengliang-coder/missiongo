# Android SDK 安全边界

## SDK Token

- Token 采用 `mg_sdk_` 前缀和高熵随机值；
- 服务端只保存 SHA-256 摘要；
- 明文只在创建时返回一次；
- Token 绑定一个产品、Android 平台和可选来源模块；
- Token 只能创建、读取自己的草稿、正式提交，并向该草稿生成的任务上传附件；
- Token 不能读取任务列表、任务详情、附件内容、时间线或管理配置；
- Token 可以设置过期时间并由管理员立即撤销。

APK 中的 Token 可以被有能力的攻击者提取，所以不能靠混淆把它变成秘密。服务端已按 Token 和操作类型执行持久化固定窗口限流；IP 限制、字节配额和异常审计仍属于后续里程碑。

## 数据限制

- 上下文最多 50 个字段；
- 单个上下文值最多 2,000 字符；
- 日志最多 500 条和 256 KiB；
- 单条日志最多 4,000 字符；
- SDK 保留宿主主动提供的诊断原文，不承诺自动遮盖敏感字段；
- 服务端再次验证数量、长度、平台和来源模块。
- 每个任务最多 10 个附件；图片、视频和日志分别执行扩展名、媒体类型和大小限制。

宿主不得把密码、真实 Token、Cookie 或完整鉴权头写入 SDK。原文保存是内部诊断策略，不代表可以绕过宿主自身的数据分级和日志治理。

## 传输

生产环境 SDK 只接受 HTTPS origin。服务地址不得包含用户名、密码、查询参数或 fragment。开发环境 HTTP 必须由宿主显式打开。

## 本地恢复数据

打开反馈入口时，SDK 会把本次标题、描述、已合并上下文、有限日志和环境快照写入宿主沙箱内由 SDK 管理的 `noBackupFilesDir` 子目录。SDK 不读取或写入宿主数据库、SharedPreferences；这些文件最大 512 KiB、24 小时过期，不参与系统备份，并在成功、取消或用户关闭最终错误后删除。

本地文件依赖 Android 应用沙箱保护，不额外承诺字段级加密。因此宿主仍不得传入密码、鉴权凭据或不适合落盘的个人敏感信息。

无界面后台队列使用同样的禁止备份目录和 24 小时上限，仅由宿主显式调用 `enqueueFeedback` 创建。WorkManager 只在网络约束满足后读取对应队列文件，不扫描宿主目录。

用户在 H5 明确选择的附件由 MissionGo 同源页面保存到 WebView 的 origin 隔离 IndexedDB，以支持 WebView 进程重建后的恢复。附件记录按草稿隔离并在 24 小时后清理；其实际配额和备份行为受系统 WebView 与宿主 App 配置影响。页面与原生 SDK 之间仍没有 JavaScript bridge。

## 不可信内容

宿主传入的标题、描述、日志、上下文和后续附件都属于不可信数据。它们只能作为工作条目内容保存，不能成为服务端、MCP 或 AI 的控制指令。
