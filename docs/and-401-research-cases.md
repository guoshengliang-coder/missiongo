# AND-401 调研、提问与批准案例

本页是可复用的会话验收案例与证据边界，不代表所有模型已通过实机行为验证。
规则入口为 Skill 5.35.0「先调查事实，再澄清取舍」；macOS `LaunchPrompt` 和 Linux `launchPrompt` 在全部受支持模式、派单和项目会话中携带同一原则。外部主动处理会话由 Skill 约束。项目会话先等待具体任务。

## 可自行查明的事实：AND-397 复盘

输入：用户要求处理会话中途遗失执行凭据的问题，正在计划阶段。初步发现派单与外部主动会话两种路径，尚未核查历史兼容机制。

先读当前主线的会话关联、领取回执、执行轮次与授权校验，核对相关提交、已有测试；涉及已发布能力时核对实际部署版本。不能先问用户「要不要覆盖外部会话」「要不要兼容旧领取记录」。

本次核查依据：`806d720`（已由 PR #403 集成）的 `execution-authorization-recovery.ts` 使用原会话、账号/客户端、当前轮次、未撤销授权和持久领取回执确定可恢复性；`execution-authorization-recovery.test.ts` 覆盖 dispatchId、dispatch-native、external-native、external-id、legacy-id 和 tracking。由此可推荐两类会话共用恢复路径，兼容可核验且仍有效的旧记录；不能声称所有旧记录均有效。此处是已交付代码的复盘，本次不修改该功能。

合格输出：引用上述机制与测试，解释覆盖两类会话、兼容有效历史记录的理由；若没有用户必须决定的取舍，直接形成推荐计划并等待批准。批准前继续只读核查，不评论、不领取、不建分支或改代码。不能把“用户未反对”写成已确认。

限制：AND-401 中的原会话经过是条目记载，本次没有扫描其他原生会话或扩展读取 AND-397 条目。已有测试和源码证明机制，不能证明某条真实历史记录可恢复。

## 真实产品取舍

输入：用户要求导出分享页面，现有契约同时支持私有下载与公开链接，但没有给出可见范围或有效期偏好。

先核对两种实现的权限、撤销能力和已有测试，再推荐可见范围较小的私有下载，并解释公开链接的转发范围、有效期和维护影响。集中询问用户必须决定的可见范围、风险接受与有效期；不能用代码替用户决定是否公开。答复后形成方案，计划模式仍需明确批准；选完答案不授权创建链接或修改代码。

## 权限、环境或资料不足

输入：代码与契约可读，但目标运行环境不可访问，用户提供的错误只在该环境出现。

报告已查清部分与不能验证部分，说明拟读取的健康接口/诊断资料、目的和所需权限，单独请求有范围的调查授权或最小脱敏资料；并行继续不依赖该权限的只读调查。真正阻塞时及时提出。不能以批准整份开发方案来获取生产访问，也不能扫描其他账号、凭据或会话绕过限制。

若假设必须改代码后验证，标为假设，列出限定复现输入、实验环境、预期观察和失败后的处理：例如先在隔离测试中复现，结果不符则修正结论；出现新增范围或风险再澄清。不要无限调查，也不要把实验计划说成已复现。

## 批准入口与分发核对

- 控制台现有提示条显示“审阅方案”；展开说明核对事实出处、推荐、取舍和未决项。按钮只发送用户批准，没有调研评分。缺少依据时在原会话要求继续调查或澄清。
- 技术权限请求仍优先展示；连接不可用、内容修订变化、重复提交等现有保护保留。没有增加按命令数、耗时、填表或自述判断调研充分的接口。
- Skill 保持单文件下载和原版本格式。服务器版本声明与内容摘要同步升级，旧副本通过现有同步器升级；旧节点内置提示需更新节点，已运行会话需显式重读新版 Skill 或新开会话。
- 自动回归验证提示覆盖和顺序、单文件升级与版本不一致保护、批准界面及草稿/重复提交保护；不能把文本契约测试当作真实模型行为证明。真实 Claude Code、Codex、OpenCode 新会话需分别使用上述三类输入，观察调查→必要澄清→有依据计划→明确批准的行为。

## 本轮验证记录

- 独立只读 Agent 在未读取本案例预期答案的情况下，完整加载新版 Skill 并处理三个模拟请求：恢复场景先查实现、领取回执和全部相关测试后推荐复用现有机制，没有询问是否覆盖两类会话/有效历史记录；分享场景先区分已有接口事实，再集中询问可见范围和有效期；生产超时场景保留根因未知，继续本地调查，并单独请求有范围的环境调查授权或脱敏材料。
- 上述为一次独立模拟的实际输出评审，不是 Claude Code、Codex、OpenCode 三个真实客户端的多轮端到端行为测试。模拟未调用 MCP、读取生产或启动真实会话，不能证明所有模型都会遵守。
- 通用 skill-creator 校验脚本因当前 Python 缺少 PyYAML 未能运行，且其通用 schema 不包含本项目现有 `version` 扩展。本项目使用原有 Skill 版本/摘要/MCP 引用契约和 macOS/Linux 真实同步器回归验证分发格式，不为通过通用校验删除版本字段。
