# AND-510：外部历史记录的 Builder 转交与重试

Builder 转交对外部会话复用现有实际活动判定，避免仅因历史处理关系或失联记录要求不可取得的停止回执。批准方案文档 ID：`36859ee0-0aba-48a9-a728-871f871f0eab`（第 1 轮 v1）。

## 原行为与复现

- 原 `BuilderHandovers.external()` 按历史业务结束事件和少量快照状态选取外部会话，`stop()` 遇到 `requires_stop=1` 就无条件受阻。
- `retry()` 复用同一标记，不重新核对当前证据。合成数据中外部进展结束、共用阻断列表已为空时，原交接仍永久受阻。
- 调查核对的线上提交与当时最新主线在三个相关实现文件没有差异；没有读取截图中其他产品条目的真实会话，也没有对生产条目执行转交。

## 当前行为与边界

| 来源与条件 | 行为 |
|---|---|
| 外部记录仅有历史进展，或快照失联、过期、节点离线且无待处理命令 | 允许交接责任，永久撤销旧授权；不制造物理停止证明 |
| 在线新鲜 active/stalled、活动回合或三种待处理命令 | 交接受阻，由原操作者处理；上报 completed 不能代替当前活动证据 |
| 原外部交接已受阻，后来证据允许转交 | 显式重试在原交接 ID 内刷新停止需求并继续，不新建交接或启动 Agent |
| 等待派单停止时，历史外部来源恢复活动 | 完成前再次检查并阻断，不能因派单收到回执就忽略其他来源 |
| 原派单已经要求停止 | 保留精确停止命令回执、健康非活动快照、离线及送达未知保护 |
| 多条目外部关系或同一原生来源的其他条目镜像 | 拒绝单条自动转交，包含已结束历史；重试与完成前也复查共享范围 |

共享范围检查发生在取消或撤权前，补齐外部来源到派单镜像的反向检查。历史进展、快照、处理轮次、条目业务状态和成果保留；A→B→A 不复活旧授权。托管/AI 执行及目标 Builder 产品操作权限保持原门禁。

允许历史责任转交不能终止旧设备进程，也无法撤销已发送到外部系统的操作。状态未知只表示没有当前活动证据，不能声称进程已停止。真正恢复活动仍需原操作者处理。

## 共用界面

`TransferBuilderModal` 与 `BuilderHandoverNotice` 复用原 `Modal`、`Select`、通知容器和主题令牌，分别说明派单停止、外部实际活动阻断、历史风险及原交接重试。提示在转交前及完成后可读，不新增解锁入口、原生协议或样式豁免。
