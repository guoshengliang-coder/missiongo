## 测试隔离修复

收尾发现既有 Agent 环境测试只覆盖了 HOME，继承的 CODEX_HOME 仍指向真实配置；模拟 Skill 下载因此覆盖了本机 Codex Skill。已用未受影响且内容一致的本机 Claude/OpenCode 5.73.0 Skill 恢复，保留本机服务器配置。恢复后核对 SHA-256 一致。

Node 测试新增统一临时 HOME、USERPROFILE、CODEX_HOME、CLAUDE_CONFIG_DIR、XDG_CONFIG_HOME，直接 Skill 用例也显式设置 Windows 用户目录；新增回归核对所有默认 Agent Skill 目标均在测试私有目录。修复后共享节点 211 项回归全部通过（21 个文件），并复核真实 Skill 摘要保持不变。没有修改共享发布工具或客户端配置。
