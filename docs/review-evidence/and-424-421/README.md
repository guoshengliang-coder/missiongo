# AND-424 / AND-421 会话反馈审计

基于 `4eaa7615`（与线上 Web 1.1.25 同一提交）加本次修复。本机 Chromium、隔离测试实例及合成会话，不是线上截图，也不是 Linux 像素比较基线。

## 共用实现与覆盖入口

| 入口 | 发现与处理 |
| --- | --- |
| Agent 控制台 · 投递状态行 | `AgentReplyFeedback` 统一用 `LoaderCircle` 转圈（排队中不再闪动时钟）；排队、发送、送达、已送达四种状态共用隐藏度量层，预留最大宽度与行高，切换状态时气泡位置和尺寸不变 |
| Agent 控制台 · 撤回编辑 | 去掉铅笔图标，改为状态文字右侧的常驻下划线文字按钮：与状态同字号、字重 600、无边框；仅排队态可操作，触控目标仍不小于 44px |
| Agent 控制台 · 空闲挂起 | 不再渲染 `.inline-error`；节点给出的挂起说明移入「运行详情」展开区，折叠时只保留中性的「已挂起」状态 |
| 条目内 `AgentSessionPanel` | 复用同一组件与 `sessionInlineError` / `sessionStatusDetail` 判定，红色错误条同样只留给真实异常 |
| 真实异常（stalled / unavailable / failed） | 保留红色错误条与原有恢复入口，异常提示范围没有被放宽 |
| 设计契约 | `docs/design-system.md` 已同步旋转图标、编辑操作字号/字重与几何稳定约定，并登记两个新增回归用例 |

## 验证边界

- 自动化已覆盖：排队→送达→已送达的气泡 x/宽度/高度不变（长短消息各一）；统一旋转图标与减少动态效果；无铅笔图标、内联下划线、同字号 600 字重；挂起会话无红色错误条、折叠时不可见、展开后可见；不可用会话仍显示红色错误条。另有 helper 单元测试覆盖两个入口共用的判定。
- 只有人在真机或真实数据上能证明：真实 Claude Code 会话空闲满 2 小时后节点上报的实际文案与挂起时机；线上会话列表与真机上的观感。本轮未连接真实节点验证这一条。
