# 评论卡片与详情布局返工

本目录仅使用隔离测试服务和合成数据。截图展示本轮任务分支，不代表正式上线或真机验收。

## 共用实现与范围

- AND-353：复用 `RecordDisclosure`，将执行状态置于右侧首行，展开/收起位于其下。摘要日期和正文首项不再叠加额外边距。复查会话、派单和非评论通知，保留两级展开、去重计数及补发确认。
- AND-352：下载按钮用 28px 半透明可见底板，44px 点击区保持；编号和下载共用媒体覆盖层令牌。评论媒体填满缩略图，编号靠左上角。复查条目媒体、评论媒体和附件展开页；下载、预览缩放、切换和评论附件归属保持。
- AND-346：失败回调按键更新提示，保留原卡片内容与返回链接；区分缺少通知、组织、投递记录和配置变化等错误。没有放宽组织、接收人绑定、配置版本和项目权限校验。

AND-346 的原始失效条件尚待确认：用户说明是新卡片，但本批三个条目均没有评论卡片发送记录，已请求来源条目编号或是否由卡片平台测试发送。不能把错误反馈修复视为初始故障已经解决。真实手机、电脑钉钉验证在修复版本获准上线后，仅向用户本人进行。

## 验证边界

浏览器回归覆盖明暗主题、媒体下载/缩放/切换/归属、执行排序/计数/两级展开、通知补发确认及加载失败。几何断言覆盖 320、375、724、768、844、1180、1440px 和三档字号。新增样式使用令牌，基线只缩减，没有扩大样式例外。

卡片回归覆盖权限、绑定变化、未知卡片、配置变化、重复提交、worker 重启后回复，以及错误响应保留原卡片字段。自动化均为合成数据；不能证明真实钉钉客户端已送达或回复已成功。
