本目录仅使用隔离测试服务和合成数据。截图展示本轮任务分支，不代表正式上线或真机验收。

## 共用实现与范围

- AND-353：复用 `RecordDisclosure`，将执行状态置于右侧首行，展开/收起位于其下。摘要日期和正文首项不再叠加额外边距。复查会话、派单和非评论通知，保留两级展开、去重计数及补发确认。
- AND-352：下载按钮用 28px 半透明可见底板，44px 点击区保持；编号和下载共用媒体覆盖层令牌。评论媒体填满缩略图，编号靠左上角。复查条目媒体、评论媒体和附件展开页；下载、预览缩放、切换和评论附件归属保持。
- AND-346：失败回调按键更新提示，保留原卡片内容与返回链接；区分缺少通知、组织、投递记录和配置变化等错误。没有放宽组织、接收人绑定、配置版本和项目权限校验。

AND-346 的来源已由用户确认是 AND-347。核对该条目的评论通知记录、生产配置及钉钉开发者后台后，发现组织 CorpId 误填为应用详情页面的 UUID；应用 Client ID 与评论模板匹配。应用凭据仍可发送卡片，但回复携带的企业 CorpId 与配置不符，被组织校验拒绝。本轮增加应用 UUID 防误填校验和配置说明，保留组织、绑定及权限检查。用户随后明确批准线上配置更正；已完成备份和事务修正，独立复核确认全部 12 条人员映射、原应用凭据及机器人配置保留。旧卡片因版本变化需重发；此处不包含生产配置或真实标识。真实手机、电脑钉钉验证在修复版本获准上线后，仅向用户本人进行。

## 验证边界

浏览器回归覆盖明暗主题、媒体下载/缩放/切换/归属、执行排序/计数/两级展开、通知补发确认及加载失败。几何断言覆盖 320、375、724、768、844、1180、1440px 和三档字号。新增样式使用令牌，基线只缩减，没有扩大样式例外。

卡片回归覆盖权限、绑定变化、未知卡片、配置变化、重复提交、worker 重启后回复，以及错误响应保留原卡片字段。新增应用 UUID 配置拒绝用例，确认配置版本和人员绑定不变；配置页面在手机、桌面与明暗主题下均验证拒绝反馈和凭据检查说明。自动化均为合成数据；不能证明真实钉钉客户端已送达或回复已成功。
