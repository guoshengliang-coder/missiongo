## 人工验收

部署包含本 PR 的服务端及 macOS 安装包后，检查首次登录、浏览器授权前后退出 App 再启动、多个设备同时授权、取消/拒绝/过期，以及断网恢复。原生 AI MCP 客户端还需单独验证新的授权码登录。

在保留旧钥匙串项的升级环境中检查冷启动、重新授权、登录保存和退出登录：界面应保持响应，等待超时应显示恢复提示，退出后重启不能恢复旧会话。不要删除 `installation-id`；它继续关联设备仓库映射与历史。ad-hoc 升级仍可能要求系统重新授权，本次不保证跨升级免授权。Security.framework 调用无法强制取消；一直不返回时需恢复系统授权或退出重启 App。
