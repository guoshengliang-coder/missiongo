## 人工验证

1. 在 Agent 控制台查看 `**我的判断：**当前正文`、`**方案： **文字`，确认粗体正常；检查引用、表格、任务列表和代码，确认代码中的星号保留。
2. 打开异常页，确认不再出现派单健康度面板。对未启动的失败派单核对重新派单确认流程；对已启动的失败会话核对回复、归档、客户端及关联条目入口与权限一致。投递不明确时应先核实，不重复发送。
3. 发布后，由人工将外部会话的最后一条关联工作标为已完成；核对该会话移入已归档，其他未完成会话保留。有未决回复时，应等取消、投递结清或人工核实后再归档。
4. 人工恢复自动归档记录，再触发相关结束检查，确认记录保留；在真实 Agent 客户端确认原始对话仍可查看。
5. 发布后核对符合条件的历史记录已补归档；仍有未结束条目、全部取消、空关联、未决回复的记录保持原状。

本地测试和浏览器模拟不能证明线上迁移已运行或真实客户端状态；这些部分需合并、发布后人工核验。本次不合并、不发布，不决定工作条目的最终验收。
