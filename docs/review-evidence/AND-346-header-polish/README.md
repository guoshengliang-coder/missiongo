# AND-346 评论头部对齐与反馈返工

本轮人工退回指出卡片顶部留白过大、回复与作者及更多按钮上下错位、悬停反馈不明显。用户选择只收紧卡片顶部，保留卡片之间的间距，并批准本轮实施及一个 PR。

## 改动与共用入口

- 复用 `CommentGroup`、`CommentBody`、原生更多菜单及主题令牌，只调整评论样式；讨论和全部动态、原评论和回复、人工和 AI 评论都沿用同一实现。
- 卡片上边距从常规 12px / 窄容器 8px 收紧为 4px，其余内边距、组间距及回复间距不变。
- 作者、回复、更多入口的首行最小高度在鼠标设备上统一为 36px，触控统一为 44px；时间及来源标记仍在下一行。先前回复独自为 44px，另外两个为 36px，顶部一致仍会使视觉中心错位。
- 回复和更多入口使用主题令牌提供悬停底色、按下底色及键盘焦点反馈，保留全局焦点环。悬停只在支持 hover 的设备上生效。
- Web 版本声明递增为 1.1.6，发布范围为 web（Web/Server）。本轮不修改评论通知、钉钉配置及服务端数据。

- 真正的鼠标输入覆盖回复及更多的悬停、按下反馈；Tab 导航覆盖回复与更多入口及焦点环。既有全文展开、作者全文查看、回复对象、附件预览/下载、讨论排序、草稿恢复、明确 @ 与本人提醒结果回归保留。

## 人工验证与交付边界

合并且发布后，在桌面检查作者、回复和三个点的对齐，悬停及按下回复，使用 Tab 检查焦点；在手机与大字号下检查操作完整可达。切换讨论/全部动态、展开长评论并回复一条已有回复，确认卡片边界和回复对象保持正确。
