## 人工回归

1. 在手机列表查看已分配、待分配、需重新分配的条目，确认编号与 Builder 一眼可区分。
2. 打开关联 Agent 会话的条目，确认摘要左侧为 Agent 与节点、状态与时间，右侧控制台入口可打开正确会话。
3. 展开执行记录，确认人工执行、多轮交接、工作范围和结果可查看，更新已有人工执行后仍能保存。
4. 查看长标题、长姓名和长来源信息，确认图标不变形、文字不横向溢出，明暗主题均可读。
5. 在 Android WebView 真机检查点击和滚动；浏览器模拟不能代替这一步。
