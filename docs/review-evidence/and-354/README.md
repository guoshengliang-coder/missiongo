## 共用实现和覆盖入口

- 列表更多菜单与详情更多菜单的单条退回、退出处理、取消使用 `TransitionNoteDialog`。
- 批量退回共用 `TransitionFiles`、`useTransitionFiles`、`TransitionAttachmentAttempt`；每个条目独立上传与提交，记录成功结果，重试跳过成功项。
- 复用 `Modal` / `useDialogDraft`、`useFileDropZone`、`DraftChatFile`、原附件校验与 `AttachmentSection`。没有增加浮层或样式豁免。
- 原因与附件 ID 在同一事务写入状态事件，上传审计保留、显示归组；不会另外创建评论。状态附件不进入原始报告图集及诊断。
- 既有状态请求保持兼容；新增可选附件 ID、幂等键、预期状态，接口见 `docs/openapi.yaml`。无需数据库迁移。

## 限制和人工验证

- 本机仅验证 Chromium。Safari、Android WebView 与 macOS 宿主实际文件选择、系统权限及返回手势需在设备上验证；未修改独立原生页面。
- 沿用每条目最多 10 个附件及现有类型/体积限制。已上传但后续提交失败的文件会保留为条目附件，弹窗明确提示；选中文件在点击确认前不上传，显式取消丢弃本地草稿。
- 批量部分成功后关闭不会撤销已成功项。操作仍为人工权限，MCP 不增加取消或验收能力。
- 本次代码与截图不代表已经合并或发布；相关交付产物为 Web/Server（`web`）。
