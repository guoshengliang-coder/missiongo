# AND-517 Agent 待发送图片标注编辑

## 行为与边界

已有会话回复与新会话首条消息：选择、粘贴或拖入图片 → 点击缩略图查看全图 → 编辑图片 → 保存回预览 → 发送编辑后的文件。复用既有彩色画笔、矩形、椭圆、撤销、缩放及平移；不新增裁剪、文字、马赛克或持久矢量笔迹。

- 保存仅替换对应的待发送 File，保持其他附件顺序与文字；预览和缩略图跟随新文件。图片在发送前不上传。
- 草稿按会话隔离，替换匹配原 File 身份。文件被替换、组件卸载或发送锁生效时，迟到导出不写回草稿。
- 上传、提交、核对和结果不明期间可预览，不能编辑。新会话首次请求冻结后同样不能编辑；历史及已投递图片不提供编辑，不改原附件 API。
- PNG 保持 PNG，其他可编辑格式输出 JPEG，名称、类型和字节保持一致；GIF 先确认转静态图片，HEIC/HEIF 明确提示无法直接编辑，不新增转码服务。导出重新校验图片 20 MiB 限额。
- 导出失败、空 Blob 或超限不卸载画布、不丢笔迹或替换原图，保留错误和重试入口。保存中不能退出或重复保存。
- 取消、关闭、Esc 和浏览器/宿主返回共用笔迹放弃确认；取消确认仍留在编辑器，确认放弃后回预览；关闭预览回到原缩略图，文字与附件仍在。

## 共用组件与覆盖入口

| 对象 | 变化 | 边界 |
|---|---|---|
| DraftChatFile | 可选 onReplace；预览中编辑、格式说明及原文件核验 | 只有明确接入的调用方出现编辑；评论及状态草稿保留原预览 |
| AgentSessionConsole | 按会话隔离的 File 替换；草稿键按会话与位置稳定 | 扩展名变化不重建预览；发送锁与权限继续生效 |
| NewSessionDraft | 替换首条消息草稿中的对应文件 | 沿用首次发送请求键及上传记录冻结 |
| lazy-image-annotator | 提取已有懒加载和局部错误边界供共用 | 编辑器继续按需加载，条目表单保留原导出 |
| ImageAnnotator | 修正底部取消绕过保护；同步保存锁及可重试错误 | 原条目、SDK 与新草稿共用；不改变原绘图与导出分辨率 |
| MediaLightbox / ZoomableImage / overlay | 沿用现有预览、缩放、焦点及返回栈 | 不新增平行浮层或样式豁免 |

新增编辑、GIF 提示及草稿保存文案走 i18n；提示颜色、圆角、字号沿用主题令牌，编辑入口沿用灯箱 44px 控件。
