## 实现边界

| 对象 | 变化 | 边界 |
|---|---|---|
| 清单 | 独立分页投影，全部／待合并／待发布 | 原会话交付确认接口保持原语义 |
| 历史 | 展示合并依据、产物版本及无需发布说明 | 不将完整交付视为人工验收 |
| 批次 | 显式仅合并、合并并发布、仅发布 | 保留原批次、权限、互斥与原参数重试 |
| 既有合并 | 原批次、head、commit 只读引用 | 禁止重复 report、repair、handoff 或恢复覆盖 |
| 发布范围 | 第二步内联全量候选、产物与额外覆盖 | 快照不代替实时 Git 和公开产物核验 |
| 范围变化 | 启动和发布阶段拦截新增或漂移范围 | 自身正常合并产生的交付按原完成依据匹配 |
| 回执 | 范围内每份交付完整覆盖后才可收尾 | 部分发布继续待发布，未知结果保留锁 |
