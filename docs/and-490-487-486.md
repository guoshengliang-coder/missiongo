## 共用实现与覆盖入口

- `DispatchDialog`：覆盖普通批量派单、新会话配置及保留的交接表单；独立集成配置采用整体配置初始化，无同轮 effect 覆盖路径，未改其行为。
- `sessionReplyPresentation`：控制台列表、控制台运行详情、条目内 `AgentSessionPanel` 共用；复用 `AgentRunDetails`、`AgentReplyFeedback`、`SessionStatusIcon` 及 i18n，不增加样式或豁免。当前选中行采用详情中的最新命令，防止较慢的列表缓存反向覆盖终态。
- `AgentAdapter.detectionReport`：旧适配器默认沿用原检测；macOS Codex 单独区分缺失和已安装但探测不确定。`NodeLoop` 不缓存失败，不用技能或资源检查把失败升级为可用，不领取该 Agent 的派单。其他 Agent 仍可上报和执行。
- 版本探测诊断仅含阶段和退出/超时/解析分类，不传原始输出、本机路径或凭据。版本未知使用空版本值，现有服务端将其视为未提供版本。
