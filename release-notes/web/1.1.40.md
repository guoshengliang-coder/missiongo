# Web 1.1.40

- Agent 诊断方案改为「会话核心摘要 + 固定版本 Markdown 文档」：会话只保留诊断结论、修改建议与待决事项，完整依据、实施步骤和验证内容进入文档，各端读取同一份原文。
- 计划文档不可覆盖，带稳定标识、处理轮次、版本和内容校验值；可在当前端直接阅读全文，节点离线后已保存文档仍可访问。
- 批准入口仍在原会话摘要与文档链接之后，批准绑定该摘要与固定文档版本；打开文档不代表批准，也不作为批准的前置条件。
- 获批文档可读回 Agent 执行上下文，并以原附件形式和摘要评论幂等归档；重复重试不会产生重复评论。
- 待验证打回后按处理轮次保存补修记录，仍有效的原批准可复用，方案实质变化时需审阅新版本。
