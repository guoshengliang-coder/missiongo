# Web/Server 1.1.19

- 外部 AI 会话可在领取条目前提交并审阅实施方案；批准后沿用同一会话领取，无需先领取才能找到审批入口。
- 明确方案的 Web 批准不再依赖原生回复连接，分别展示批准已保存和继续消息的投递状态；领取前清楚显示“待领取”。
- 修复 MCP 新协议原生人工确认的衔接，批准结果绑定原账号、客户端与方案修订；同一已批准方案直接复用，旧客户端提供原会话的 Web 衔接入口。
- 待审批关联不会生成执行凭据、处理日志或执行阻塞；Builder 交接不会误伤同会话中其他条目的处理授权。
- MissionGo Skill 更新至 5.38.0。通用 Plan 模式切换和普通聊天不冒充正式批准记录。

AND-405 的变更由 Web/Server 和公开 Skill 提供，无需因此更新原生节点安装包。
