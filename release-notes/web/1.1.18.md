# Web/Server 1.1.18

- 普通项目会话按所选权限启动，修复选择自动审查后仍进入只读、会话内切换无法生效的问题；同时覆盖 Codex、Claude Code 和 OpenCode。
- 普通讨论和经确认的需求登记不再套用代码实施方案门禁；工作条目开发继续保留正式方案批准和原生模式确认。
- 新会话名称可区分，并同步到原生 Agent；改进后台任务仍运行时的会话状态提示。
- Codex 会话默认轻量同步近期摘要，旧历史按需加载，减少超大历史对回复和停止的影响。
- MCP 可读取已有会话历史与方案批准记录。

权限修复需要 macOS 0.4.72 或 Linux 节点 0.1.7。更新节点后，已有被错误限制的普通会话可重新选择权限恢复；尚未批准的条目开发方案仍保持限制。
